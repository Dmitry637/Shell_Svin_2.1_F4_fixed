# Dependency Graph CLI — этап 1

Минимальный Java CLI-прототип для будущего инструмента визуализации графа зависимостей пакетов. На первом этапе приложение загружает пользовательские параметры из INI-файла, печатает их в формате `ключ=значение` и проверяет корректность. Получение зависимостей и построение изображения графа — следующие этапы проекта; в этом прототипе изображение не создаётся.

## Требования

- JDK 17 или новее.
- Для запуска и тестирования достаточно `javac` и `java`. Maven-файл также включён для стандартной сборки проекта в Maven-окружении.

## Запуск

**Windows:** запустите `run.bat` в корне проекта (либо `scripts\\run.bat`). Батник сам переключается в каталог проекта, поэтому его можно запускать из другого текущего каталога.

**Linux/macOS:** из корня проекта выполните `./scripts/run.sh`.

По умолчанию используется `config.ini`. Чтобы выбрать другой конфигурационный файл, передайте путь в качестве первого аргумента:

```text
./scripts/run.sh path/to/config.ini
```

```text
scripts\\run.bat path\\to\\config.ini
```

Скрипт компилирует исходники в каталог `out/` и запускает CLI. Код возврата `0` означает успешную проверку, `1` — ошибки конфигурации, `2` — ошибку использования CLI.

## Конфигурация INI

Пример `config.ini`:

```ini
[app]
package_name = example-package
repository_mode = local
repository = test-repository.txt
package_version = 1.2.3
graph_output_file = dependencies.png
```

Параметры:

| Ключ | Описание и проверка |
|---|---|
| `package_name` | Имя пакета; буквы, цифры, точка, `_` и `-`, без пробелов и знаков-разделителей по краям. |
| `repository` | Путь к файлу тестового репозитория или URL репозитория. |
| `repository_mode` | `local` для файла на диске или `remote` для HTTP(S)-URL. |
| `package_version` | Версия, например `1.2.3` или `1.2.3-SNAPSHOT`. |
| `graph_output_file` | Имя/путь выходного PNG; родительский каталог должен существовать и быть доступным для записи. |

В режиме `local` параметр `repository` должен указывать на существующий читаемый файл. В режиме `remote` проверяется синтаксис HTTP(S)-URL, сетевое соединение на этом этапе не выполняется. Относительные пути к репозиторию и выходному изображению разрешаются относительно каталога выбранного INI-файла. Выходной PNG на первом этапе не создаётся.

Поддерживаются комментарии с `;` или `#`, пустые строки и секция `[app]`. Дубликаты и неизвестные ключи, записи вне `[app]` и некорректные строки отображаются как ошибки конфигурации. Приложение выводит все пять параметров даже при ошибках; отсутствующие значения помечаются как `<не задано>`. Проверки собирают все найденные ошибки за один запуск, а не завершаются на первой ошибке.

## Тесты

**Windows:** запустите `test.bat` в корне проекта (либо `scripts\\test.bat`). Тесты собираются и запускаются отдельно от приложения.

**Linux/macOS:** `./scripts/test.sh`

Тесты автономные и не требуют загрузки сторонних библиотек. Проверяются валидная конфигурация, ошибки каждого параметра, локальный файл репозитория, некорректный удалённый URL, неизвестные/повторяющиеся INI-ключи и вывод всех параметров.

## Сборка Maven

В окружении с установленным Maven можно выполнить:

```text
mvn package
```

Исполняемый JAR будет собран в `target/dependency-graph-cli-1.0.0.jar`. Зависимостей времени выполнения у приложения нет.

## Состав этапа

- CLI-точка входа `Main`.
- Собственный INI-парсер без библиотек менеджеров пакетов.
- Валидация всех пяти настраиваемых параметров.
- Конфигурация-пример и тестовый файл репозитория.
- Автономный тестовый набор и скрипты Windows/Linux/macOS.
